# PunyaKios Payment Gateway for Fluent Forms

Accept QRIS payments through your Fluent Forms. Ideal for donations, simple service payments, or custom order forms.

## Features
- **Flexible Forms**: Add PunyaKios payment fields to any Fluent Form.
- **Auto-Callback**: Fluent Form entries are marked as paid automatically.
- **Easy Configuration**: Simple API Key setup.

## Installation
1. Upload and activate the `punyakios-fluent` plugin.
2. Go to **Fluent Forms > Settings > Payment Settings**.
3. Select **PunyaKios** as your payment provider.
4. Input your **Merchant API Key**.
5. Enable PunyaKios in your individual form's payment settings.

## Requirements
- WordPress 5.0+
- Fluent Forms Pro (for payment features)
- PHP 7.4+
